# 理科解析：萬物的法則之眼（Eye of the World Law）v3.5

數學、化學、物理、生物、地球科學、互動工具與升學備戰整合網站。採用清楚分類的資料夾結構，所有主要功能皆有獨立 HTML 頁面。

## v2.9 題庫品質改善
- 新增考點分類與概念去重：完整題庫模式優先保留不同考點，合併只換數字或同一公式反覆考的題型。
- 10／20 題測驗先抽不同考點；若可用考點不足，才允許同考點出現第二種題型。
- 使用 localStorage 記錄已抽過的題目，後續測驗優先安排尚未做過的題目。錯題重做仍保留原有功能。
- 題庫仍需持續擴充更有情境、圖表判讀與多步推理的原創題，去重機制不能取代高品質命題。

## 本版新增
- 選修數學、選修物理、選修化學互動課程：空間向量、條件機率、矩陣、電場、電路、波動、化學平衡、酸鹼、氧化還原等。
- 新增生物與地球科學課程：遺傳、演化、生態、板塊構造、鋒面天氣、恆星與宇宙等。
- 新增 108 道原創選擇題，分成選修數學、選修物理、選修化學、生物、地球科學、跨科綜合六類，每類 18 題。加上原有 17 題，題庫共 125 題。
- 練習中心新增科目分類、10／20／完整題庫抽題、選修／分科備戰範圍，原有逐題解析、成績紀錄與錯題重做保留。
- 新增「分科備戰」專頁，整理大考中心分科測驗與 110 學年度以前舊制指考、學測、課綱與會考官方入口。
- 保留原有 44 個獨立章節頁、工具、學習進度與深色模式。

## 檔案結構

```text
/                         網站根目錄
├── index.html            唯一首頁入口
├── README.md             專案說明與部署方式
├── assets/
│   ├── css/style.css     共用樣式與深色模式
│   └── js/script.js      共用互動功能
├── pages/                主要功能頁（依用途分類）
│   ├── tools/             計算器、繪圖、化學與物理工具
│   ├── learning/          教學學院、章節地圖、題庫、生物與地科入口
│   ├── lessons/           各主題獨立教學頁
│   ├── exam/              分科備戰與官方考題入口
│   └── progress/          學習進度與計算紀錄
├── units/                 完整章節（依科目分類）
│   ├── math/              數學章節
│   ├── chemistry/         化學章節
│   ├── physics/            物理章節
│   ├── biology/            生物章節
│   └── earth/              地球科學章節
└── docs/                  專案檢查與維護文件
    └── TEST_REPORT.md
```

根目錄不再放置重複的舊版功能 HTML、CSS 或 JavaScript；首頁只有 `index.html`，其他頁面依照用途與科目收納。

## 部署
將 ZIP 解壓縮後，把 ZIP 內的 `index.html`、`assets/`、`pages/`、`units/`、`docs/` 與 `README.md` 直接放到 GitHub repository 根目錄（不要再額外包一層資料夾），使用 GitHub Pages 部署。網站不需要 API key 或後端。
